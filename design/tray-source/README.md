# GCloud SQL Proxy — macOS Tray Icons

Assets are transparent and intended for a macOS menu bar / Tauri tray.

States:
- disconnected: muted/low-opacity status
- connecting: white status dot + subtle ring
- connected: white status dot
- error: Apple-style red status dot
- paused: white status dot with pause glyph

Recommended:
- Use the 18px SVG/PNG for 1x.
- Use the 36px PNG for @2x.
- Keep the PNGs as non-template images so the translucent logo + white status treatment is preserved.

## What this app actually embeds

(Added by engineering, not the designer.)

The **36px** PNGs, for all four wired states. `tray-icon`'s macOS backend sets the
`NSImage` point size to a hardcoded 18pt and keeps the decoded pixels as the
image's representation, so the pixel dimensions choose the backing-store density
rather than the drawn size: 36px is a pixel-exact @2x for an 18pt image. This
matches the recommendation above. An earlier iteration embedded the 18px set on
the mistaken theory that a larger PNG would overflow the ~22pt slot; it does not,
and the 18px set rendered at 1x (soft) on a Retina display.

`paused` is delivered but not wired up — the app has no pause concept. The 18px
PNGs and the SVGs are kept as the reference delivery.

Both appearance variants are generated by `design/generate-icons.py`: the
dark-menu-bar set is the delivery copied verbatim, the light-menu-bar set is its
mechanical recolour (see that script and `design/solve-tray-ink.py`).
